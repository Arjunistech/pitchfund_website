# PitchFund – Startup Pitch Event Website

A multi-page website for a startup pitch and fundraising event.

## Pages
- **Home** (index.html) – event overview
- **Events** – event schedule and details
- **Jury** – judging panel
- **Sponsors** – event sponsors
- **Winners** – results
- **Register** – participant registration
- **Contact** – contact details

## Tech Stack
HTML, CSS

## How to Run
Clone the repo and open `index.html` in any browser:
`git clone https://github.com/Arjunistech/pitchfund_website.git`
